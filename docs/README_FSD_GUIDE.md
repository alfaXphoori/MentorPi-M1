# MentorPi M1 - Full Self-Driving (FSD) Guide

เอกสารนี้อธิบายถึง **ลำดับขั้นตอนการเปิดใช้งาน** ระบบขับเคลื่อนอัตโนมัติ (Full Self-Driving) ของหุ่นยนต์ MentorPi M1 ซึ่งใช้สถาปัตยกรรมแบบ Mission Manager เพื่อจัดการความปลอดภัยและการตัดสินใจ

---

## 🚀 ลำดับการเปิดใช้งาน (Execution Order)

เพื่อให้ระบบ FSD ทำงานได้อย่างสมบูรณ์ ต้องเปิดระบบตามลำดับดังต่อไปนี้:

### Step 1: เปิดระบบพื้นฐานและเซ็นเซอร์ (Base Bringup)
ต้องเปิดการเชื่อมต่อกับฮาร์ดแวร์ทั้งหมดก่อน (มอเตอร์, กล้อง, LiDAR, IMU)
```bash
# รันคำสั่งนี้ใน Terminal ที่ 1
ros2 launch bringup bringup.launch.py
```
*รอจนกว่าเซ็นเซอร์ทั้งหมดและกล้องทำงานเรียบร้อย*

### Step 2: เปิดระบบตรวจจับป้ายจราจรด้วย AI (YOLOv5 Perception)
เปิด Node สำหรับประมวลผลภาพจากกล้องเพื่อหาป้ายจราจร โดยใช้โมเดล `traffic_signs_640s_7_0` ที่เทรนมาเฉพาะ
```bash
# รันคำสั่งนี้ใน Terminal ที่ 2
ros2 launch yolov5_ros2 yolov5_ros2.launch.py model:="traffic_signs_640s_7_0"
```
*ขั้นตอนนี้จำเป็นมาก เพื่อให้ FSD นำข้อมูลไปใช้ใน `yolo_logic_node`*

### Step 3: เปิดระบบ FSD และสมองกล (FSD Mission Manager)
รันสคริปต์หลักที่เราได้พัฒนาขึ้น ซึ่งจะเปิดระบบรักษาเลน, ระบบหลบหลีก, ตรรกะป้ายจราจร และสมองกลจัดการ (Mission Manager)
```bash
# รันคำสั่งนี้ใน Terminal ที่ 3
ros2 launch mycar fsd.launch.py
```
*(หรือสามารถใช้สคริปต์ที่เตรียมไว้: `bash src/mycar/scripts/start_fsd.sh`)*

## 🧠 สถาปัตยกรรมการตัดสินใจ (Priority System)

ระบบ `MissionManager` จะตัดสินใจสั่งการมอเตอร์โดยเรียงลำดับความสำคัญ (จากสูงสุดไปต่ำสุด) ดังนี้:

1. **🚨 LiDAR Safety (Priority 1 - สูงสุด):**
   * หาก LiDAR ตรวจพบสิ่งกีดขวางในระยะอันตราย (น้อยกว่า 0.1m หรือ 10cm) รถจะ **หยุดทันที (Emergency Stop)** ไม่ว่าโหมดอื่นจะสั่งอะไรก็ตาม
   * หากตรวจพบในระยะ 0.25m (25cm) รถจะทำการ **หักหลบ (Avoiding)**
2. **🚦 YOLO Maneuvers (Priority 2):**
   * หากเห็นป้ายจราจร (เช่น ป้ายให้เลี้ยวขวา) รถจะเข้าสู่โหมด Maneuver ทันที
   * **IMU Stabilized:** ในระหว่างการเลี้ยวขวา 90 องศา ระบบจะใช้ข้อมูลจาก IMU (เข็มทิศ) มาช่วยคุมความเร็วการเลี้ยวให้แม่นยำที่สุด จนกว่าจะครบองศาที่กำหนด

3. **🛣️ Lane Keeping (Priority 3):**
   * หากทางปลอดภัยและไม่มีป้ายจราจร รถจะขับตามเส้น (สีเหลือง/สีขาว) ไปเรื่อยๆ เป็นค่าเริ่มต้น (Normal Driving)

4. **🛑 Fallback (No Input):**
   * หากไม่มีข้อมูลใดๆ ส่งเข้ามา (หลุดเลน, ไม่เห็นป้าย) รถจะหยุดเพื่อความปลอดภัย

## 🔍 การตรวจสอบสถานะแบบ Real-time (Monitoring)

คุณสามารถดูว่าตอนนี้สมองกลของรถ (Mission Manager) ตัดสินใจใช้โหมดไหนอยู่ ได้โดยการเปิด Terminal ใหม่และรันคำสั่ง:

```bash
ros2 topic echo /mission_status
```

**สถานะที่จะแสดง:**
* `SAFETY_OVERRIDE` = รถหยุดฉุกเฉินเพราะ LiDAR เจอสิ่งกีดขวาง
* `YOLO_MANEUVER` = รถกำลังเลี้ยว หรือ ทำตามคำสั่งป้ายจราจร (ใช้ IMU ช่วย)
* `LANE_KEEPING` = รถกำลังวิ่งตามเส้นปกติ
* `NO_INPUT_STOP` = รถหยุดเพราะไม่พบเส้นหรือไม่มีคำสั่ง

---
*Note: สามารถปรับแต่งระยะเบรก, ความเร็ว, และสีของเส้นที่ต้องการจับ (เหลือง/ขาว) ได้ที่ไฟล์ `src/mycar/config/params.yaml`*
